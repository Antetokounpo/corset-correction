# Guide de contributions

Merci de consulter ce guide! Il comporte des instructions afin de normaliser toute contribution à ce répertoire. 

Veuillez consulter notre [Code de conduite](./CODE_DE_CONDUITE.md) afin que tout contributeur soit respecté. 

## Conventions du projet 

### Language

Un language simple et clair est favorisé. Pour encourager la clarté, nous conseillons d'éviter toute abréviations, ou le jargon très technique. 

## Soumettre des modifications

Les commits de vos modifications de la branche main doivent être effectués dans de nouvelles branches. Veuillez nommer vos branches avec la convention de [Conventional Branch, version 1.1.0](https://conventionalbranch.org/#summary). 

Les titres de vos commits doivent résumer la nature de vos modifications de façon claire et simple. 

Pour fusionner votre branche, envoyez un pull request aux modérateurs (Danika Duval ou Antoine Reid). Avant l'envoi, veuillez vous assurer d'avoir effectué les tâches suivantes: 
- Vérifiez que votre titre résume simplement la nature des modifications apportées
- Ajoutez une description avec une liste claire et complète de tous les changements que vous avez apportés
- Si les modifications sont en lien avec un issue, veuillez inclure le titre de cet issue ainsi que son numéro

## Signaler des problèmes

Si vous identifiez des problèmes, "bugs", veuillez d'abord vérifier que ce problème n'a pas déjà été signalé. Sinon, veuillez ouvrir un nouvel issue. Avant l'envoi, veuillez vous assurer d'avoir effectué les tâches suivantes [1]:
- Vérifiez que votre titre résume simplement la nature du problème
- Expliquez clairement la nature du problème dans la description
- Inclure les versions de logiciels que vous utilisez
- Insérez l'extrait de lignes de commandes qui causent le problème
- Listez les démarches que vous avez effectué pour régler le problème
- Veuillez spécifier si vous avez terminé vos démarches ou si vous planifiez en faire d'autres
